about=Profile Plot draws elevation profiles from any number of rasters along a line you draw on the map or a selected line feature. One shortcut (assign it yourself in Settings > Keyboard Shortcuts) opens the dock and starts drawing. The plot updates live while you draw, including the segment following the mouse. Native-cell sampling walks every pixel the line crosses (nothing is skipped), with optional 1 cm stations and bilinear interpolation. Hover and crosshair inspection, live length / ΔZ / average slope, a table with CSV export and export of the alignment to a temporary layer are included. Rendering uses QPainter with cached curves and a background reader with tile caching, so it works offline with no extra dependencies.
